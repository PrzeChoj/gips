# Project matrix onto a permutation-invariant space

Project `S` onto the space of symmetric matrices invariant under the
cyclic group generated by `perm`. Entries that must be equal under this
symmetry are replaced by their average.

## Usage

``` r
project_matrix(S, perm, precomputed_equal_indices = NULL)
```

## Arguments

- S:

  A square empirical covariance matrix to be projected. (See the `S`
  parameter in the
  [`gips()`](https://przechoj.github.io/gips/reference/gips.md)
  function). For optional multi-sample use, `S` can be a list of
  covariance matrices; see the **Multi-sample** section below. When it
  is not positive semi-definite, it shows a warning of a class
  `not_positive_semi_definite_matrix`.

- perm:

  A permutation to be projected on. An object of a `gips` class, a
  `gips_perm` class, or anything that can be used as the `x` argument in
  the
  [`gips_perm()`](https://przechoj.github.io/gips/reference/gips_perm.md)
  function.

- precomputed_equal_indices:

  This parameter is no longer used and will be deleted in v1.4.0.

## Value

The matrix `S` projected on the space of symmetric matrices invariant by
a cyclic group generated by `perm`. See **Covariance estimation** for
its statistical interpretation.

When `S` is a list, returns a list of projected matrices.

## Details

The permutation can be specified in advance or selected using
[`find_MAP()`](https://przechoj.github.io/gips/reference/find_MAP.md).
Model selection by MAP concerns the cyclic group; the subsequent
projection estimates the covariance matrix within the selected model.

The projection implements [Definition 3 from
references](https://arxiv.org/abs/2004.03503).

## Covariance estimation

Let `Z` contain `n` observations in rows. The function returns the
projection of the supplied `S` without changing its normalization:

- If the mean is known to be zero and `S = crossprod(Z) / n`, the
  projection is the covariance MLE in the specified symmetry model, when
  that MLE exists.

- If `S = cov(Z)`, the projection retains the denominator `n - 1` used
  by [`stats::cov()`](https://rdrr.io/r/stats/cor.html). For the full
  Gaussian likelihood maximized over both an unrestricted mean and a
  covariance matrix with the specified symmetry, the covariance MLE
  would be `(n - 1) / n * project_matrix(S, perm)`, when it exists.

For `S = cov(Z)` with `was_mean_estimated = TRUE`, `gips` uses the
projection without this rescaling, and
[`logLik.gips()`](https://przechoj.github.io/gips/reference/logLik.gips.md)
uses `n - 1` in its likelihood calculation. This is the package's
convention based on centered data, distinct from the full Gaussian
likelihood described above. See the **Estimated mean** subsection in
[`vignette("Theory", package = "gips")`](https://przechoj.github.io/gips/articles/Theory.md).

## MLE availability

`project_matrix()` does not receive the sample size and does not check
whether an MLE is available. It can return a singular projected matrix.
For a corresponding `gips` object `g`,
[`summary.gips()`](https://przechoj.github.io/gips/reference/summary.gips.md)
reports the sample-size threshold in `summary(g)$n0`. The field
`summary(g)$MLE_available` combines the sample-size check with a
numerical positive-definiteness check of the projection, using the
package's convention described above.

## Multi-sample

When `S` is a list of matrices (as stored in a multi-sample `gips`
object), `project_matrix()` applies the same permutation projection to
each element and returns a list of projected matrices of the same
length.

## Examples

``` r
p <- 6
my_perm <- "(14)(23)" # permutation (1,4)(2,3)(5)(6)
number_of_observations <- 10
X <- matrix(rnorm(p * number_of_observations), number_of_observations, p)
S <- cov(X)
projected_S <- project_matrix(S, perm = my_perm)
projected_S

# Plot the projected matrix:

g_MAP <- find_MAP(g, max_iter = 10, show_progress_bar = FALSE, optimizer = "Metropolis_Hastings")
```
